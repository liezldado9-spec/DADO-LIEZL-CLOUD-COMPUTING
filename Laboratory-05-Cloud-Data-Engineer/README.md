# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible object storage server using MinIO and Docker. I created a storage bucket named `client-photos` and uploaded a test file through the MinIO Web Console.

## Objectives

* Differentiate Block, File, and Object Storage.
* Deploy MinIO using Docker.
* Access a cloud service through a web interface.
* Create a storage bucket.
* Upload objects to cloud storage.
* Document cloud storage operations using Markdown.

## Tools Used

* KillerCoda Playground
* Ubuntu
* Docker
* MinIO
* GitHub
* Web Browser

## Skills Learned

* Using Docker to deploy a cloud service.
* Using MinIO object storage.
* Using Linux command-line commands.
* Creating and managing storage buckets.
* Uploading objects to cloud storage.
* Writing technical documentation using Markdown.
