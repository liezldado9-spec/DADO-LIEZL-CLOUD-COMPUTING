# Reflection

This lab activity helped me to gain a better understanding of what goes on in a "cloud" environment. Prior to the activity, I primarily considered cloud computing as merely providing services via the internet. Working with KillerCoda, I've realised that cloud computing requires other pieces of infrastructure in order to work as well.

I understood that there was a use for compute, storage, networking and operating system resources. Compute resources are used to run tasks and interpret commands on the server. Storage: Where files and system data are stored. Networking enables the virtual environment to connect with one another by the use of network connections. The operating system handles these resources, and also offers me a terminal to communicate with the server. All these are part of the cloud environment and contribute to its functionality.

These concepts were explained to me with KillerCoda, as I could explore a real Linux environment rather than just reading about cloud infrastructure. By using these commands, I determined that I was using: Ubuntu 24.04.4 LTS, 1 CPU core, 1.9 GiB of RAM, and a main disk of 19 GB. I could see the information first-hand and it helped me to grasp the concepts.

I also learned that knowledge of cloud infrastructure is necessary for IT studies because many of the present day applications rely on the servers and cloud services. By being familiar with these basic components, I can troubleshoot systems, understand how applications are hosted and be prepared for future IT work. This activity also made me realize that being able to access online services is only half the equation, but also having some understanding of the infrastructure that enables those services to exist.
