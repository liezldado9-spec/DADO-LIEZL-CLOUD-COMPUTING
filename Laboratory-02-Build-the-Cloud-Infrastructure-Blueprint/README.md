# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Objective

The aim of this activity is to gain insight in a Linux cloud environment, identify the infrastructure components of the cloud environment, compare the most important cloud providers and develop a simple cloud infrastructure architecture.

## Cloud Infrastructure Components

The four main cloud infrastructure components identified are:

1. **Compute Resources** – Used for running applications, commands and services.
2. **Storage Resources** – To store files, programs, system data and other information.
3. **Networking Resources** – Enables computers, virtual machines and services to communicate.
4. **Operating System** – Controls system resources and enables users to interact with the virtual machine.

## Cloud Provider Comparison

The three cloud providers compared are:

- **Amazon Web Services (AWS)**
- **Microsoft Azure**
- **Google Cloud Platform (GCP)**

They offer the same computing, storage, networking and operating system infrastructure services.

## Cloud Architecture

The cloud infrastructure follows this basic flow:

**Users → Network → Compute → Storage**

The architecture diagram depicts the relationship between user connection via the network to computing resources and storage resources.

## Key Findings

Ubuntu 24.04.4 LTS, one CPU core, 1.9GiB of RAM, 19 GB main disk are used by the Linux environment in the KillerCoda investigation. Other things mounted in the environment are file systems, hostname and IP addresses.

The activity illustrated three types of resource usage: compute, storage, and networking, and showed how they all collaborate in a cloud environment.
