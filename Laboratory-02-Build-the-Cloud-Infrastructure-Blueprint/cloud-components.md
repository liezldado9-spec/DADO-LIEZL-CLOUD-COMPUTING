# Cloud Infrastructure Components

## 1. Compute Resources

**Purpose:**  
Compute resources are used to run applications, commands, and services.

**In cloud computing:**  
They allow users to run programs without needing to acquire high-performance physical computers. Cloud providers can also scale computing resources up or down depending on the workload.

**Relation to my KillerCoda Linux environment:**  
My KillerCoda environment is a virtual machine with a Linux operating system, which allows me to issue commands and execute tasks. I used commands such as `df -h`, `hostname`, and `hostname -I` in this computing environment.

---

## 2. Storage Resources

**Purpose:**  
Storage resources are used to store files, programs, system data, and other information.

**In cloud computing:**  
Cloud storage allows data to be saved and retrieved without relying only on the user's local computer. It also makes storage management and expansion easier.

**Relation to my KillerCoda Linux environment:**  
I can view the storage available in my Linux environment using the `df -h` command. It displays the available, used, and total storage of the environment.

---

## 3. Networking Resources

**Purpose:**  
Networking resources allow computers, virtual machines, and services to communicate with each other and access networks.

**In cloud computing:**  
Networking allows cloud resources to share data, communicate, and provide services across a network.

**Relation to my KillerCoda Linux environment:**  
I checked the IP addresses of my Linux environment using the `hostname -I` command in KillerCoda. This shows that the environment has network connections that allow it to communicate through network interfaces.

---

## 4. Operating System

**Purpose:**  
An operating system controls computer resources and provides the connection between the hardware and the applications and commands running on the computer.

**In cloud computing:**  
Cloud virtual machines need an operating system to manage resources and allow users to interact with the virtual machine.

**Relation to my KillerCoda Linux environment:**  
My KillerCoda environment uses Linux, which allows me to use the terminal to run commands, manage files, check storage, and perform other system tasks.
